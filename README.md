## ⚡ Overview

A bespoke, high-performance personal developer portfolio engineered with **React 19**, **Vite 6**, and an **Obsidian & Crimson Red Cyber-Glassmorphism** visual theme. 

Designed from scratch for zero runtime lag, instant sub-second asset delivery, and responsive adaptability across all device form factors (mobile, tablet, desktop, and 4K displays).

### 🌌 Visual Philosophy
- **Palette**: Obsidian Pitch-Black (`#080808`) foundation paired with intense Crimson Red (`#ff0033`) specular lighting.
- **Glassmorphism**: Authentic frosted glass cards featuring `backdrop-filter: blur(12px) saturate(180%)`, soft curved borders (`rounded-3xl`), and multi-layer specular highlights.
- **Micro-Interactions**: Direct DOM matrix 3D tilt cards driven by `requestAnimationFrame` with **0 React state re-renders** for a silky 120 FPS response.

- **🔴 High-Performance Neural Mesh**: Local, ultra-lightweight Particle engine running an interactive red node network with cursor repel, click push, and tab-sleep throttling (0% CPU when blurred).

## 💻 Local Development

Clone the repository and spin up the local development server:

```bash
# 1. Clone the repository
git clone https://github.com/Umar-Adnan/portfolio.git

# 2. Navigate to project root
cd portfolio

# 3. Install dependencies
npm install

# 4. Start Vite development server
npm run dev
```

Visit `http://localhost:3000` in your browser to view the portfolio.

## 📦 Production Build

To test and compile an optimized production distribution:

```bash
# Compile minified chunks into /dist
npm run build

# Preview the production build locally
npm run preview
```

The production output generates isolated, long-term cached bundles:
- `vendor-[hash].js`: React 19 runtime
- `icons-[hash].js`: Lucide UI icon set
- `index-[hash].js`: Portfolio application logic & components

## 🌐 Deploy to Vercel

### Method 1: Continuous Deployment via GitHub (Recommended)
1. Push your repository to your GitHub account (`@Umar-Adnan`).
2. Log into [Vercel](https://vercel.com) and click **"Add New..."** &rarr; **"Project"**.
3. Select your `portfolio` repository and click **"Import"**.
4. Vercel automatically detects the Vite preset:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**. Future pushes to `main` will build and publish automatically.

### Method 2: Direct CLI Deployment
```bash
npm install -g vercel
vercel login
vercel --prod
```
